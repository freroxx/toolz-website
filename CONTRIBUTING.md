# Contributing to the Toolz Website

The website ([toolz-app.vercel.app](https://toolz-app.vercel.app)) is the landing page for Toolz. Contributions for bug fixes, design polish, responsiveness fixes, and documentation improvements are welcome.

## Tech Stack

- **Framework**: Vite + React + TypeScript
- **Styling**: Tailwind CSS
- **Motion**: Framer Motion
- **Icons**: Lucide React
- **Deployment**: Vercel

## Local Development

```bash
# Clone
git clone https://github.com/freroxx/toolz-website.git
cd toolz-website

# Install & Run
npm install
npm run dev

# Verify build
npm run build
npm run preview
```

## Pull Request Rules

1. **Keep it clean**: Avoid adding heavy external libraries for minor tasks.
2. **Responsive**: Test your changes on both mobile screens (<450px) and desktop.
3. **Screenshots**: Any visual change must include before/after screenshots in the PR description.
4. **License**: Your contributions are submitted under the **GNU General Public License v3.0 (GPL-3.0)**.
