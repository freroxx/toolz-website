# Security Policy

If you find a security issue on the Toolz website or its backend serverless endpoints, please report it responsibly so it can be fixed.

## Reporting

- **Email**: `frerox.toolz@gmail.com`
- **Subject**: `[SECURITY] toolz-website report`

Please do not open public issues. Include details of the vulnerability (SSRF, XSS, token leakage, etc.) and steps or a script to reproduce.

I will acknowledge your email as soon as possible and push a fix to production once verified.

## Safe Harbor

Security research conducted in good faith without accessing private data, disrupting service, or publishing 0-days prematurely is protected and will not face legal retaliation.
