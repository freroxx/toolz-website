# Accessibility Statement for Toolz Website

We want [toolz-app.vercel.app](https://toolz-app.vercel.app) to be easy to read and navigate for everyone.

## Features

- **Semantic HTML**: Navigation, headers, sections, and footers use proper HTML landmarks.
- **Keyboard Navigation**: Buttons, dialogs, and links can be navigated via `Tab` and activated with `Enter` or `Space`.
- **Contrast**: Text and key UI components are styled with high-contrast colors against dark surfaces.
- **Reduced Motion**: Framer Motion transitions honor system `prefers-reduced-motion` settings.

## Feedback

If something on the website doesn't work with your screen reader, has poor contrast, or breaks with keyboard navigation, please let me know so I can fix it:

- **Email**: `frerox.toolz@gmail.com` (subject: `[ACCESSIBILITY] toolz-website`)
- **GitHub**: Open an issue on [GitHub Issues](https://github.com/freroxx/toolz-website/issues)
