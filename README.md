## ✨ Key Features

| Feature | Description |
|---|---|
| 📊 **Live Download Counter** | Real-time aggregation of total downloads across all GitHub releases |
| 📲 **Dynamic Download Dialog** | Architecture-aware (ABI) detection to guide users to the correct APK |
| 🎨 **Expressive M3 Design** | Material 3 design tokens, dynamic containers, surface elevations & adaptive layouts |
| 🧩 **Module Showcase** | Interactive presentation of the 50+ precision instruments in Toolz |
| 📰 **News & Changelog** | Curated news feed, release notes, and version announcements |
| 🔍 **Spec Page** | Device specification lookup powered by GSMArena integration |

## 🛠️ Tech Stack

- **Framework** — [Vite](https://vitejs.dev) + [React](https://react.dev) + [TypeScript](https://www.typescriptlang.org)
- **Styling** — [Tailwind CSS](https://tailwindcss.com) with Material 3 Expressive tokens
- **Motion** — [Framer Motion](https://www.framer.com/motion) (with reduced-motion support)
- **Icons** — [Lucide React](https://lucide.dev)
- **Deployment & Edge Functions** — [Vercel](https://vercel.com)

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org) v18+
- npm

### Installation & Development

```bash
# Clone the repository
git clone https://github.com/freroxx/toolz-website.git
cd toolz-website

# Install dependencies
npm install

# Start the development server
npm run dev
```

The local development server runs at `http://localhost:5173`.

### Build & Production Preview

```bash
# Production bundle
npm run build

# Preview build locally
npm run preview
```
